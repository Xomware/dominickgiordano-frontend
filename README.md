# dominickgiordano-frontend

Personal resume site for Dominick Giordano: [dominickgiordano.com](https://dominickgiordano.com).

[`Xomware/dominickgiordano-infrastructure`](https://github.com/Xomware/dominickgiordano-infrastructure).
