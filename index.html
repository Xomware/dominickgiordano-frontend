About

I’m a senior software engineer at Lumist Labs. With my team I build the products behind an applied-AI consultancy for mid-market companies: an executive readiness diagnostic, an agent platform for non-technical teams, a training platform, and the internal tools the company runs on.

Outside work I build apps I actually use, under the Xomware name. Spotify stats, fantasy football tools for my leagues, a lifting tracker, a recipe log. Most run Angular or SwiftUI up front and Python on AWS Lambda behind, with Terraform and GitHub Actions doing the deploys.
